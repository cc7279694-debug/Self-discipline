# 观已Mirra

一款面向个人阅读与学习场景的 Android Local-first 应用，重点解决“想学习却迟迟无法开始”和“开始后容易被手机重新拉走”两个问题。

产品通过 Intent、行为启动脚本、Session、专注干预、恢复机制和轻量阅读记录，形成“产生学习意图—真正开始—维持专注—分心后回来—记录进度—下次继续”的完整闭环。
