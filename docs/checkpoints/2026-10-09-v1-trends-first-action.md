## Implemented behavior

- Mine directly shows the recent seven-day reading duration, an actual daily chart, Start Conversion and confirmed distraction Recovery. Detailed analysis is secondary; original pages/notes/session totals remain expandable rather than removed.
- Trends keeps 7/30/90/ALL and groups the original facts into 启动 / 专注 / 恢复. Details are expandable. No score, ranking, streak or AI judgement.
- Daily reading duration uses the existing Phase 2 NORMAL-ended reading eligibility and whole-Session `endedAt` local-date cohort. It is not effective focus, a split across midnight or one-seventh of a weekly total. Frozen trusted Maintain/Recover/Start definitions remain unchanged.
- Fixed ranges include actual local dates and known empty days. Unknown/damaged-only duration is unavailable, not zero; mixed valid and invalid facts disclose a confirmed subtotal. Unreadable previous periods do not manufacture growth. ALL totals remain full; its sparse chart explicitly shows at most the latest 90 recorded dates. Existing ALL scalar medians remain O(N), not constant-space.
- Book creation and action editing require a nonblank explicit choice. The suggestion is initially unselected; selecting it is a real UI action. A bounded validator rejects controls, excessive length, numeric/punctuation-only text, known legacy auto-templates and obvious goals such as “今天读30页”. This is not semantic proof that arbitrary free text is actionable, nor proof of a physical action.
- Start emphasizes the chosen step and uses 开始准备. Blank/known auto-generated legacy actions require confirmation before a new Intent; action editing pins the selected book while saving. Preparation displays the action and only 我已完成这一步，开始阅读 converts the Intent to a Session.
- A lawful pre-existing Active Intent remains valid and can be explicitly completed, with its existing mutation guard and display fallback. No historical fact is rewritten. Expired Intent TIMEOUT is durably committed even when the requested next book still needs an action.
