## What Was Built

- 单书已结束 Session 历史，ABNORMAL 和其他非正常结束记录保留显示并明确排除统计。
- 7→14→30 天动态窗口、近期整体阅读速度、预计剩余阅读时间。
- 反映完整自然日阅读频率的日历推进速度，以及通过硬门槛后的自然完成日期范围与高/中/低可信度。
- “我的”最近 7 天正常 Session、阅读时长、推进页数、Note 数和前 7 天时长比较。
- Learning Item 详情中的平面 Mirra Blue 分析区；Start、Navigation 和既有业务状态机不变。

## Frozen Semantics

- `pagesRead = max(0, endPage - startPage)`，不加 1。
- 只统计 `NORMAL` 且完整、正时长、非未来的 Session。
- 零推进正常 Session 计入 Session 数、阅读日、时长和整体速度分母；窗口总推进为 0 时不预测。
- 整体速度按总页数 / 总时长，日历推进速度按总页数 / 完整 7、14 或 30 个本地自然日。
- 日期预测资格优先于 Confidence；`robustCV > 0.75` 隐藏日期，LOW 不显示日期。
- HIGH / MEDIUM 日期范围分别为中心日期的 10% / 20%，最早不早于明天。
- PAUSED / COMPLETED 保留历史和近期事实，但不显示未来预测。

## Architecture

```text
Compose
  → LearningItemDetailViewModel / ProfileViewModel
  → ReadingAnalyticsService / CompletionPredictionService
  → ReadingAnalyticsRepository
  → Room DAO read projections
```

聚合结果不持久化；Room 业务表仍是唯一事实源。查询使用 Session + Note COUNT 投影，避免 N+1。`java.time` 通过 Android core library desugaring 支持 minSdk 23。

## Data Safety

- `MirraDatabase.version` 保持 3。
- 未新增 Entity、Table、Column、Index 或 Migration。
- 导出的 `1.json`、`2.json`、`3.json` 未变化。
- 分析只读，不修改 Learning Item、Intent、Session、Note、Image、Topic 或 SearchFts 数据。

## Verification

- JVM：统计、窗口、本地时区/DST、跨年、robustCV、Confidence、日期范围、零推进与异常排除。
- Room/Instrumented：历史排序、Note 计数、边界查询、最近 14 天来源和 10,000 Session 单投影查询。
- Compose/端到端：Learning Item 节奏与历史、“我的”7 天摘要、ABNORMAL 标识和 Navigation 接线。
- 全量回归覆盖 Phase 1、2A、2B、Start、2C、Theme、Migration、图片补偿与主题生命周期。
- `lintDebug`、`assembleDebug`、APK 覆盖安装、离线启动和强停/冷启动均纳入最终验收。

## Known Limitations

- 预测依赖用户如实更新页码；数据不足、无推进、高波动或低可信度时主动隐藏完成日期。
- 首版不提供图表、长期 Dashboard、全局 Session History、目标日期或异常提醒。
- Phase 2 只有 Session 总时长，不计算“有效专注时间”；该指标必须等待 Phase 3 的 SessionSegment。

## Next Stage Should Inherit

Module 2D 完成后停止。Phase 3 如获单独授权，必须继承现有 Session 数据语义，不得把 Phase 2 的整体阅读速度改名为有效阅读速度，也不得让 Start 变成 Analytics Dashboard。
