# Module 2A Acceptance Checkpoint

## Goal

在不改变 Room Schema v1 的前提下，完成 Learning Item 生命周期与 Note 完整管理，并保持 Phase 1 学习闭环、离线能力和异常恢复不回归；不进入 Module 2B。

## Verified Completed

- Learning Item 支持暂停、恢复和完成；Phase 2 不允许已完成内容恢复。
- 只有进行中内容能成为主线、创建 Intent 或开始 Session。
- 暂停与完成在事务内检查当前状态及该内容的 Active Intent / Session，并同步解除主线；恢复更新时间但不自动恢复主线。
- `createIntent()` 与 `startSession()` 在各自数据库事务内部、实际插入前再次验证 Learning Item 状态。
- Note 支持全部列表、详情、独立创建、正文/语义类型/页码编辑、二次确认删除，以及语义类型与 Learning Item 组合筛选。
- 独立 Note 不预建空白记录；满足有效归属与非空正文后才首次写入，之后固定 ID 并使用 500ms debounce 与生命周期 flush。
- Note 页码与编辑不改变 Session 或 Learning Item 阅读进度。

## Data Safety

- Room Entity、Table、Column、Index 与 `MirraDatabase.version = 1` 均未改变。
- Schema Export `1.json` 与冻结基线 Git blob 均为 `bb92ea9ac29eecf06a9a0951be254fc30ac05ed4`。
- 没有新增或注册 Migration。
- 从 commit `2f66397` 构建 Phase 1 APK，创建 Learning Item、主线、Session、进度、总结和 Note 后，以 Module 2A APK 覆盖安装；所有旧数据可直接读取。

## Known Limitation
